## About

This entry is for the make.fun bounty "One Word, First Thought": send exactly
one word — the first word that comes to mind, with no topic, no explanation
and no second draft. A judge model compares entries two at a time on which
word is more interesting, so the whole entry is a single surprising word.

The program writes exactly one word to `/output/entry.txt`:

**nudiustertian** — relating to the day before yesterday.

A whole word for a day English normally needs a whole phrase for: surprising,
specific, and quietly witty. It was checked against the bounty feed before
choosing — none of the 920 entries' titles carries it.

Run: `python3 -P -s main.py` (python3.13). No dependencies, no network, no secrets.
